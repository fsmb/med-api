# ImlccAbmsBoard

IMLCC ABMS board

| Name | Type | Required | Description |
| - | - | - | - |
| memberBoardName | string | No | Board name |
| memberBoardShortName | string | No | Short board name |
| meetsMoc | string | No | Meets MOC |
| certificates | [ImlccAbmsCertificate[]](imlcc-abms-certificate.md) | No | ABMS certificates |

*Note: Any fields marked as deprecated will be removed in a future version of the API. New code should not rely on these fields. Existing code should be updated to use alternative fields.*
