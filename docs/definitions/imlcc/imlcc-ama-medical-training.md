# ImlccAmaMedicalTraining

AMA medical training for IMLCC

| Name | Type | Required | Description |
| - | - | - | - |
| programName | string | No | Program name |
| institutionName | string | No | Institution name |
| institutionState | string | No | Institution state |
| specialtyDescription | string | No | Specialty |
| programType | string | No | Program type |
| trainingStatus | string | No | Training status |
| beginDate | string (date) | No | Start date |
| endDate | string (date) | No | End date |

*Note: Any fields marked as deprecated will be removed in a future version of the API. New code should not rely on these fields. Existing code should be updated to use alternative fields.*
